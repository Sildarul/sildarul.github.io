Comment on travaille

Nos choix de traduction

Sild'arcade production — projet Reset 60. La base, en une page.

Traduire un jeu de console, c'est faire entrer du français dans une boîte qui n'a pas été prévue pour lui : quelques cases de 8 pixels, une police sans accents, une cartouche qu'on ne peut pas agrandir impunément. Voici ce qu'on essaie de faire, et pourquoi.

01

Tout en français

Pas de mélange. Si un mot anglais reste à l'écran, c'est qu'on n'a pas pu faire autrement — et on le dit dans le lisez-moi du jeu. Les menus, les messages de combat, les écrans de fin, les noms de classes, les descriptions d'objets : tout y passe.

02

Les unités aussi

Les miles deviennent des kilomètres, les pieds des mètres, les livres des kilos, les °F des °C — avec les bonnes valeurs converties, pas juste le mot changé. Un compteur qui dit « 100 » en miles dit « 160 » en kilomètres. Un joueur français doit pouvoir lire les chiffres sans faire de calcul.

03

La place décide

On écrit la forme la plus complète que la place permet, et on ne descend d'un cran que si ça déborde. Ce n'est pas un mot par notion, c'est une échelle :

AnglaisSi ça rentreSi ça manqueEn dernier recours
GAME OVER PARTIE FINIE TERMINÉ PERDU
PASSWORD MOT DE PASSE CODE DE JEU CODE
PRESS START APPUIE SUR LE BOUTON START APPUIE SUR START FAIS START

C'est pourquoi le même jeu peut dire « APPUIE SUR START » sur un écran et « FAIS START » sur un autre : même règle, deux largeurs.

Et jamais « PRESSE START » : on presse un citron, on appuie sur un bouton.

04

Les abréviations, en dernier

Une abréviation n'est pas un confort, c'est un pis-aller quand le mot entier mord sur autre chose. OBJ pour OBJET dans un inventaire de trois cases, oui. OBJ dans une phrase, non.

05

Les accents, on se bat pour

Une police de jeu n'en a pas. On les dessine. Si la place au-dessus de la lettre manque, on réduit l'accent, jamais la lettre, et on ne descend jamais toute la police d'un pixel pour faire de la place. On ne renonce qu'après avoir tout essayé, et le lisez-moi le dit.

06

Ce qu'on ne traduit pas

Une signature ne se francise pas : noms d'auteurs, sociétés, copyright, restent mot pour mot. Mais ce qui les introduit est au joueur : MUSIC BY → MUSIQUE DE, PRESENTS → PRÉSENTE. Et un intitulé de poste se traduit : c'est un métier, pas un nom.

07

Les noms qu'on connaît

Quand le jeu vient d'une série qu'on a vue en français, on reprend les noms de la VF : Fred Pierrafeu, pas Fred Flintstone. On joue à ces jeux pour retrouver quelque chose.

08

Les joueurs

« 1P / 2P » devient « J1 / J2 ». Mais quand le jeu parle au joueur, il ne dit pas « J1 » : il dit « toi », ou son nom.

09

On écrit comme on parle

Le mot vivant l'emporte sur le mot juste. On ne répète pas deux fois le même terme dans un passage, même si l'original le fait. On ne calque pas l'ordre des mots anglais. On ne raconte rien que le texte d'origine ne raconte pas.

10

Ce qu'on s'interdit

  • Toucher au code du jeu pour gagner des lettres : si ça ne rentre pas, on reformule.
  • Retraduire un jeu déjà traduit par un autre groupe.
  • Sortir quoi que ce soit sans relecture : chaque patch est refabriqué depuis la cartouche d'origine et vérifié octet par octet dans les deux sens.
11

Et le 60 Hz

Le projet a commencé là. Les versions européennes tournaient en 50 Hz : plus lent, des bandes noires, la musique qui traîne. On travaille sur les versions américaines ou japonaises, en 60 Hz, telles que les jeux ont été conçus — et on y met le français. Seule exception : un jeu né en Europe, qui n'a jamais existé ailleurs.

Chaque jeu relu nourrit le suivant. Une règle tirée d'un seul jeu reste une piste tant qu'un autre ne l'a pas confirmée.
